# Spellwalker

A free-range browser magic adventure built with William — explore procedurally generated worlds, defeat monsters and named bosses, level up your wizard, and unlock new classes as you progress.

## How to play

Just open `spellwalker.html` in any modern browser (double-click the file, or drag it into a browser tab). No install, no server needed — it's a single self-contained HTML file.

- **Move:** WASD / arrow keys, or drag the on-screen joystick on touch devices
- **Attack:** spacebar / click, or tap the ATK button
- Class-specific abilities (Dash, Shadow Step, Zeus's Judgement, Rainbow Nova, Possess) appear as extra on-screen buttons once you unlock them

Progress (unlocked wizards and your current run) is saved automatically in the browser's local storage.
